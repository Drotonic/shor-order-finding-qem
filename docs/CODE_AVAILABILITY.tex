\paragraph{Code and data availability.}
The study code and recorded simulation data are publicly available at
\texttt{https://github.com/Drotonic/shor-order-finding-qem}, release \texttt{v0.1.2}.
It implements shot simulation, stochastic folding, extrapolation fits,
probability reconstruction, paired bootstrap, and order-recovery evaluation.
The release assets provide the measurement outcomes and counts, reconstructed
parent distributions, and completed bootstrap caches, including the
reset-readout sensitivity records and strict order-recovery probabilities.
The README documents the commands linking these inputs to the reported
point estimates and percentile summaries, together with file checksums
and analysis settings.

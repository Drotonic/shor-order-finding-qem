\paragraph{Code availability.}
The source code supporting the study is organized in the currently private
repository \texttt{https://github.com/Drotonic/shor-order-finding-qem}.
The code version for this statement is \texttt{v0.1.0}.
The repository contains simulator and analysis source, a portable CPU
demonstration using synthetic counts, and historical analysis source.
It does not contain the actual shot records, bootstrap checkpoints,
compiled-operation pickle files, or manuscript and figure assets.
Consequently, the code-only release does not by itself reproduce the reported
numerical results or the exact historical paired-bootstrap draws.
Software-license selection is pending; repository access does not constitute
a license grant. No archival DOI is currently assigned.

\paragraph{Code availability.}
The study code is publicly available in the repository
\texttt{https://github.com/Drotonic/shor-order-finding-qem}, version \texttt{v0.1.1}.
It implements shot simulation, stochastic folding, extrapolation fits,
probability reconstruction, paired bootstrap, and order-recovery evaluation.
The README documents the commands, inputs, outputs, and analysis settings.

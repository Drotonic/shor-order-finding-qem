\paragraph{Code and data availability.}
The study code, recorded simulation data, and two recorded hardware datasets
are publicly available in release \texttt{v0.2.1} at
\url{https://github.com/Drotonic/shor-order-finding-qem/releases/tag/v0.2.1}.
It implements shot simulation, stochastic folding, extrapolation fits,
probability reconstruction, paired bootstrap, and order-recovery evaluation.
The seven simulation archives are unchanged from release \texttt{v0.1.2}, and
the two hardware archives are unchanged from release \texttt{v0.2.0}.
The unified asset catalogue and checksum file cover all nine ZIP archives.
The simulation assets provide measurement outcomes and counts, reconstructed
parent distributions, and completed bootstrap caches, including reset-readout
sensitivity records and strict order-recovery probabilities.  The hardware
assets provide the acquired records and fixed analysis products for the two
reported devices.  The README documents download, checksum and extraction
steps, including the separate extraction directories required by the two
hardware archives.  The archived hardware products support inspection and
figure reproduction; the current automation is not claimed to replay those
historical hardware executions end to end.
